# Nuviko — исправленная версия интерфейса

Откройте `index.html` в браузере либо загрузите всю папку на хостинг. Главная иллюстрация встроена непосредственно в HTML, поэтому не теряется при открытии единственного HTML-файла. SVG-иконка остаётся отдельным файлом `favicon.svg`.

## Исправлено

- Адаптивная вёрстка для мобильных экранов и узких окон; добавлены ограничения на переполнение.
- Иллюстрация человека на главном экране встроена в HTML.
- Кнопки «Назад» на страницах регистрации, загрузки, результатов и тарифов ведут в соответствующие разделы.
- Переходы используют историю браузера: системные кнопки «Назад» и «Вперёд» работают.
- Демо-аккаунт, оставшиеся запросы и статус входа сохраняются в `localStorage` данного браузера после перезагрузки.
- После повторного открытия страницы входить заново не нужно, если пользователь не нажимал «Выйти» и не очистил данные сайта.

## Что представляет собой демо

Регистрация — **локальная имитация**, а не защищённый аккаунт на сервере. Пароли не сохраняются и не проверяются: не используйте свой настоящий пароль. Данные сохраняются **только в том же браузере и для того же адреса сайта**. Если открыть сайт с другого устройства, очистить данные браузера или открыть его по другому адресу, аккаунт будет недоступен. Для настоящего продукта потребуются серверная авторизация, база данных и серверный учёт бесплатных анализов.

Фотография отображается только в браузере и не отправляется на сервер. Оценки результата демонстрационные и не связаны с содержимым фото. Оплата не подключена.

## Состав

- `index.html` — сайт со стилями, скриптами и встроенной иллюстрацией.
- `favicon.svg` — иконка сайта.
- `hero-statue.png` — отдельная копия главной иллюстрации для возможного редактирования.


## Мой день, прогресс и настройки

- «Мой день»: 5 заданий из меняющегося по дате набора, отметки «Сделал» / «Не успел». Повторное нажатие снимает отметку.
- В 23:59 по локальному времени устройства день закрывается: результат, процент выполнения и мотивирующая фраза фиксируются. Если сайт был закрыт, итог рассчитывается при следующем открытии. До полуночи кнопка следующего дня недоступна; после полуночи нужно нажать её вручную. После нескольких пропущенных дней открывается текущая дата.
- Календарь сохраняет итоги заданий и новые тренировочные сессии: название, выполненные упражнения, фактическое время с отдыхом, без пауз. Старые прохождения без измеренного времени задним числом не восстанавливаются.
- Настройки: звуковые сигналы, тихая синтезированная фоновая мелодия, напоминания и их время. Музыка по умолчанию выключена. Звук запускается после взаимодействия с сайтом.
- Напоминания работают только при открытом сайте (вкладка в фоне может задерживаться браузером). При разрешении Notification API используются системные уведомления, также появляется сообщение на сайте. Для уведомлений при закрытом сайте нужны серверный планировщик и Web Push; они пока не подключены.
- Данные разделены по email демо-аккаунта и хранятся локально в `nuviko_daily_v1`. Очистка браузера удалит историю; синхронизации между устройствами нет.

Файлы: `daily.js`, `daily.css`. Проверки: `node daily.test.cjs`, `node workouts.test.cjs`.


## Видео упражнений лица

В активной тренировке лица доступен переключатель «Анимация / Видео». Файл `assets/face-workout.mp4` — предоставленный пользователем ролик. Для каждого упражнения показывается его фрагмент по уже существующим временным отметкам программы; на отдыхе остаётся анимация. Видео по умолчанию без звука, звук и приближение управляются только кнопками на правой панели. Нативные элементы управления, перемотка и взаимодействие с видео отключены. Таймер управляется кнопками тренировки. Переключение сохраняет текущий этап и оставшееся время; выбранный режим запоминается в браузере. Сервер поддерживает MIME video/mp4 и HTTP Range для перемотки.

В «Мой день» добавлены плавное появление карточек, фоновое движение и отклик при выполнении. При системной настройке уменьшения движения анимации отключаются.


## Обновление режима тренировок

В тренировке лица оставлено только видео, переключатель анимации удалён. Во всех программах удалены автоматические этапы отдыха «Время выдохнуть»: упражнения идут подряд, ручная пауза остаётся доступной. Новая длительность: лицо 8:00, глаза 4:00, спина 6:40. Сохранённые сессии с перерывами автоматически переводятся на соответствующее упражнение с сохранением выполненных этапов и времени текущего упражнения. У остальных программ сохраняется их текущий показ упражнений до добавления видео.


## Видео для всех трёх программ

Добавлены пользовательские видео `assets/eyes-workout.mp4` («Глаза охотника») и `assets/back-workout.mp4` («Ровная спина»). Все программы используют одинаковый видеоплеер без перемотки и нативных элементов управления. Пауза, приближение и звук — на правой панели; упражнения идут без автоматических перерывов. Для каждой программы используются её собственные временные отметки ролика. Обложки каталога, страницы программы и постеры видео заменены кадрами из соответствующих роликов (`face-cover.jpg`, `eyes-cover.jpg`, `back-cover.jpg`).


## Полноэкранный режим

Кнопка «На весь экран» открывает всю область тренировки через Fullscreen API; при недоступности API используется экран поверх страницы. Внутри доступны таймер, пауза, звук, приближение и выход. После окончания таймера снизу плавно появляется карточка с названием следующего упражнения и кнопкой перехода. Полный экран сохраняется при смене этапов и паузах, закрывается после завершения тренировки, по Esc или кнопке «Закрыть». Уменьшение движения в настройках системы отключает анимацию карточки.


### Горизонтальный плеер на телефонах

При полноэкранном просмотре на устройствах с сенсорным вводом запрашивается `screen.orientation.lock('landscape')` после входа в Fullscreen API. При выходе блокировка снимается. Если браузер не поддерживает поворот или запрещает его, в портретном положении CSS поворачивает весь плеер на 90° вместе с таймером, кнопками и карточкой следующего этапа. При физическом повороте телефона CSS автоматически возвращает обычную горизонтальную компоновку. На ПК ориентация не блокируется.


### Заполнение мобильного экрана

Полноэкранный контейнер больше не поворачивается: вращается только внутренняя сцена с видео и управлением. Это устраняет конфликт с размерами, которые браузер принудительно задаёт Fullscreen API. Видео использует `object-fit: cover`: заполняет экран с сохранением пропорций, при отличающемся соотношении сторон возможна обрезка краёв.


### Скрытие управления на телефонах

В мобильном полном экране весь интерфейс управления изначально скрыт. Касание показывает его на 5 секунд; каждое следующее касание обновляет отсчёт. После окончания этапа карточка перехода появляется автоматически и также скрывается через 5 секунд: вернуть её можно касанием. Таймер скрытия работает и на паузе. Скрытые кнопки исключаются из взаимодействия, а первое касание только показывает интерфейс. На ПК управление остаётся видимым.
